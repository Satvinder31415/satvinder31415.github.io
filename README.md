# Satvinder Singh — Academic Website

A static academic website with light and dark themes. No installation, build step, or server backend is required.

## Preview

Open `index.html` in a browser. The website also works through any local static web server.

## Publish with GitHub Pages

1. Copy this folder's contents to your repository, keeping `index.html` at the repository root. Include the photo, stylesheet, script, favicon, and `.nojekyll` file.
2. For a personal site at `https://Satvinder31415.github.io/`, use a public repository named `Satvinder31415.github.io`. A different repository name works as a project site at `https://Satvinder31415.github.io/REPOSITORY-NAME/`.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then your branch (usually `main`) and **/ (root)**. Save.
4. GitHub will show the website address when deployment completes.

All local asset paths are relative, so the same files work for both personal and project Pages sites.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Update the content

- Edit `index.html` to update your profile, research interests, publications, education, experience, and contact links. Content is readable even without JavaScript.
- Replace `Satvinder.jpg` to update the portrait. Preserve the filename or update its reference in `index.html`.
- The publication list is maintained manually in `index.html`. No résumé is included in the website.
- Edit the color variables at the top of `styles.css` to adjust both themes.
- The theme starts with the visitor's system preference. The top-right moon/sun button saves their choice in browser storage when available.

Publications, author order, venues, education, experience, and profile links were taken from the supplied résumé, with subsequent content edits requested by the owner. The layout takes inspiration from https://gty929.github.io/ with an original implementation.
