# Institution logos

Local copies of institution artwork, used beside work experience entries or retained for future use. The marks belong to their respective institutions.

- `purdue.png`: https://www.purdue.edu/home/wp-content/mu-plugins/boilerup-wp/favicon/favicon-96x96.png
- `iit-madras.png`: https://www.cse.iitm.ac.in/img/iitm-logo.png
- `iisc.png`: https://www.iisc.ac.in/wp-content/uploads/2020/08/IISc_Master_Seal_Black_Transparent.png
- `cmi.png`: https://www.cmi.ac.in/pix/cmi-header.png

Keep the logo PNG files alongside `index.html` when uploading the website to GitHub Pages. All artwork has transparent backgrounds and is stored unchanged from its source. The stylesheet supports white monochrome versions of the CMI and IISc marks in dark mode. No white background or border is added behind the logos.
